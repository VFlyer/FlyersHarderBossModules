Keep Talking and Nobody Explodes Mod 1ll 4

On the Subject of 1ll 4

“Out of all the evil things he spoke to me, there is still one that he never speaks.”

The contents of this manual denote the Glitched difficulty preset of this module, which may be overridden.

Before the first solved module, barring any ignored modules, the module will cycle between a series of characters that represent the balanced base the module used:

  • Base q use digits whose values range from 0 to q-1. If q is odd, a balanced base can be formed using integers -(q-1)/2 to (q-1)/2 inclusively, which includes 0.
  • Digits in balanced bases whose values are positive will have an inverted counterpart, both value and display; segments that would be off will be on, and vice versa.

Selecting the submit button will pause/resume the digit display, and the arrows can be used to manually scroll through the displays.

For each channel the digit that is not displayed corresponds to the initial value for the given base, or V0.

After the first solve, three values will be displayed on the module, corresponding to their RGB channels. These channels additively mix. An LED will also light up with 1-3 possible distinct colors in the process. These will change when an unexcluded module has been solved. The defuser may select a channel to disable to get a better view of a particular stage. At least one channel must be active per stage when toggling.

For each stage, apply the function corresponding to the color(s) of the LED and the segments displayed. Use the tables provided to determine the resulting values.

If the stage indicator opens up to reveal a button and there is at least 1 other non-ignored module not solved, you must enter submission for this stage. A correct submission will NOT disarm the module but adds a random percent of time corresponding to the current time on the bomb. Missing this submission will not result in a strike but decrease the countdown timer by 10%. This penalty will INCREASE by 10% for every missed submission after the first and has no effect if the timer ticks up, instead of down.

Stage Calculation Overview

The amount of distinct colors the LED flashed correspond to a series of operations that must be performed to obtained the resulting values of each stage.

If at any point after applying the operations/functions:

  • Any channel's value exceeds (q-1)/2: repeatedly subtract (q-1)/2 from that result, until its value is less than or equal to (q-1)/2.
  • Any channel's value falls below -(q-1)/2: repeatedly add (q-1)/2 to the result, until its value is greater than or equal to -(q-1)/2.
  • The resulting combined true value exceeds ((q-1)/2)3+((q-1)/2)2+((q-1)/2): repeatedly subtract ((q-1)/2)3+((q-1)/2)2+((q-1)/2) from the true value, until it is less than or equal to ((q-1)/2)3+((q-1)/2)2+((q-1)/2)
  • The resulting combined true value falls below -((q-1)/2)3-((q-1)/2)2-((q-1)/2): repeatedly add ((q-1)/2)3+((q-1)/2)2+((q-1)/2) to the true value, until it is greater than or equal to -((q-1)/2)3-((q-1)/2)2-((q-1)/2)

n is the current stage number, stage 1 counts as n = 1.
Dn refers to the individual true value of each channel displayed on this stage.
Cn refers to the combined true value displayed on this stage whose digits are ordered by the three channels, RGB, with B corresponding to the least significant.
Vn refers to the resulting individual true value of each channel for this stage.
Tn refers to the resulting combined true value for this stage.
|X| is the absolute value of X. Absolute values are treated as positive during calculations.
max(X, Y) refers to the largest value out of X and Y; min(X, Y) refers to the smallest.
% refers to the modulo operator. This operation respects signs and follows the same rules as if the value falls out of the range. For X % Y, if Y is 0, leave X unchanged.
Primary colors used in this manual are Red, Green, Blue; Secondary being Cyan, Magenta, Yellow; and blacK and White corresponds to Any other color.
P3, S3, A2, all reference the function of the color that did NOT flash within their corresponding color groups.
True values always account for its inversions.

Submission

When the module is ready to solve, all segments will blank out, alongside the left LED displaying the current color, . Select the channel, represented by the squares, to toggle their values, then select the segment to apply the resulting color to it. The up and down arrows can be used to turn all of the channels on or off respectively when inputting.

The 3 channels must correspond to a valid character encoded on the module when submitting, otherwise, the module will strike and force the user to review the character displays again.

An incorrect submission with valid characters will turn correct segments green, incorrect segments red, and forces the user to view all stages again.

Use the arrows and component selectors to scroll through the stages that were missed, with the outer-most arrows cycling by a factor of 10 stages. When ready, press the submit button to try again.

Appendix: Difficulty Settings (Presets)

This module may be configured to have some or all of its behaviors modified. Preset difficulties are provided here:

Stabilized

  • The balanced base used is between 41 to 71 inclusive, with basic characters ordered in the appendix provided. All 3 channels will share the same set of characters.
  • 1 color and 2 color operators will only show up. 2 color operators show up 4 times less frequently than 1 color operators.
  • Colors displayed on all stages are always correct in the manual.

Glitched

  • The balanced base used is between 57 to 87 inclusive, some characters that represent those values will be replaced entirely with other familiar characters. 2 channels will share the same order of characters.
  • 2 of the channels will use the same balanced base; with the other channel having a different base.
  • Any color operators will show up. 3 color operators show 4 times up less frequently than 2 color operators, which show up 4 times less frequently than 1 color operators.
  • Primary components are swapped and/or inverted, the component selectors must be used as a reference instead.
  • If early submission is enabled, early submissions are separated by at least 10 stages, including the initial stage.

Chaotic

  • The balanced base used is between 71 to 101 inclusive, some characters that represent those values will be replaced entirely, sometimes with randomly picked segments. No channel will contain the exact same order of characters.
  • All 3 channels will use different balanced bases, which each channel having different maxmium values.
  • 2 color and 3 color operators will show up more frequently.
  • Colors displayed will no longer correspond to their correct colors, the component selectors must be used as a reference instead.
  • If early submission is enabled, early submission are separated by at least 20 stages, including the initial stage.

Appendix: Difficulty Settings (Custom)

This module may be configured to have some or all of its behaviors modified. Custom settings are defined here, prefixed with _1ll4:

  • EnableEarlySubmission: Enables early submission for this module. See the first page on how early submission works.
  • ModuleDifficulty: Sets the difficulty of the module via the preset difficulties. Custom enables a lot of options below:
  • UpperMaxValBal: Sets the largest value in any base that can be rolled onto the module. Clamped to 9 - 4095.
  • LowerMaxValBal: Sets the smallest value in any base that can be rolled onto the module. Clamped to 9 - 4095.
  • ColorCycleDifficulty: 1 only inverts the component colors; 2 cycles the component colors; 3 inverts and/or cycles the component colors; 4 is every color scrambled. 0, or any invalid value makes the colors respect that of the manual provided.
  • Op1ClrWeight: Sets the frequency of 1 color operators that can show up on the module. 0 or lower prevents 1 color operators from showing up.
  • Op2ClrWeight: Sets the frequency of 2 color operators that can show up on the module. 0 or lower prevents 2 color operators from showing up.
  • Op3ClrWeight: Sets the frequency of 3 color operators that can show up on the module. 0 or lower prevents 3 color operators from showing up.
  • ChannelsPerStage: Configures the amount of channels used to calculate each stage. Clamped to 1 - 4. If set to 1, only Black and White will be used as possible colors for the segments. DO NOT SET THIS VALUE TO 4 UNLESS YOU KNOW WHAT YOU ARE DOING.
